### 📚 Ohara — Library Management System

A group project focused on applying **data structures, algorithms, and systems programming** to a practical library management system.

**Primary Language:** C

**Data Structures**

| Structure | Purpose |
| --- | --- |
| Linked List | Core book catalogue |
| Binary Search Tree | Book searching |
| HashMap | Fast ISBN-based retrieval |
| Queue | Book waitlists |
| Stack | Transaction/history tracking |

**Algorithms & Concepts**

* Merge Sort
* BST insertion, search and deletion
* Linear Search
* Hashing and collision handling
* Binary file I/O using `fread` / `fwrite`
* Dynamic memory allocation using `malloc` / `free`
* Modular program structure
* Input validation and duplicate ISBN protection

A parallel Python implementation with **45 passing unit tests** was used to verify logic and algorithm correctness during development.
